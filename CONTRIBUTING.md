# Contributing

## Install

```powershell
npm run install:app
```

## Develop

```powershell
npm run dev
```

## Verify Before Sending Technical Feedback

```powershell
npm test
npm run build
```

## Contribution Rules

- Describe issues with a reproducible configuration.
- For app-vs-game calculation bugs, attach the exported issue JSON and an Eco **Room Details** screenshot.
- Keep changes small and focused.
- Do not modify `outputs/eco-data.json` without explaining which Eco version was used.
- Add or update tests when housing calculation behavior changes.
