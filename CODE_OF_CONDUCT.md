# Code of Conduct

## Our Pledge

We want Eco Housing to be a welcoming and useful project for players, testers, and contributors. Everyone participating in this project is expected to communicate with respect, patience, and good faith.

## Expected Behavior

- Be respectful when discussing bugs, data mismatches, and implementation choices.
- Assume good intent, especially when someone reports confusing behavior.
- Provide clear reproduction details when reporting issues.
- Keep feedback focused on the app, the data, or the game behavior being compared.

## Unacceptable Behavior

- Harassment, insults, threats, or personal attacks.
- Discriminatory language or behavior.
- Repeated hostile or disruptive comments.
- Sharing private information without permission.
- Spam or off-topic promotion.

## Reporting

If you see behavior that breaks this Code of Conduct, please report it by opening a GitHub issue or contacting the repository owner. Reports should include enough context to understand what happened.

Project maintainers may remove comments, close issues, block users, or take other reasonable actions to keep the project healthy.

## Scope

This Code of Conduct applies to this repository, GitHub issues, pull requests, discussions, and any project-related communication.

## Attribution

This Code of Conduct is inspired by common open-source community guidelines and adapted for this project.
