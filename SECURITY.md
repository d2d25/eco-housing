# Security Policy

## Supported Versions

Eco Housing is currently in beta. Security fixes are handled for the latest version on the default branch.

| Version | Supported |
| --- | --- |
| `0.1.x-beta` | Yes |
| older versions | No |

## Reporting A Vulnerability

Please do not publish security issues publicly before they have been reviewed.

To report a vulnerability, contact the repository owner through GitHub or open a private security advisory if GitHub enables that option for this repository.

Please include:

- a clear description of the issue;
- steps to reproduce it;
- the affected page or feature;
- whether user-provided JSON, imported files, or generated Eco data are involved;
- any suggested fix, if you have one.

## Scope

Security reports are especially useful for:

- unsafe import/export JSON handling;
- cross-site scripting risks;
- unsafe handling of generated Eco data;
- dependency vulnerabilities;
- deployment or GitHub Pages configuration issues.

## Out Of Scope

The following are usually out of scope unless they create a real security risk:

- calculation mismatches with Eco;
- visual layout bugs;
- missing item data;
- feature requests;
- issues requiring administrator access to a user's own Eco server.

## Response

This is a small community project, so response time may vary. Valid reports will be reviewed, fixed when practical, and credited if the reporter wants credit.
